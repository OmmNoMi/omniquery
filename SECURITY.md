## Reporting a Vulnerability

We take the security of OmniQuery, its offline-first data pipelines, and user data very seriously. If you discover a security vulnerability, please report it privately to our security team.

### How to Report

* **Email**: Send your disclosure to **[omniquery@ommnomi.com](mailto:omniquery@ommnomi.com)**.
* **Do NOT create a public GitHub issue** for undisclosed security vulnerabilities.
* Please provide:
  * A clear description of the vulnerability and attack vector.
  * Step-by-step reproduction instructions or a minimal proof-of-concept (PoC).
  * Impact assessment on data confidentiality, integrity, or availability.
  * Any suggestions for mitigation or remediation.

### Response Timeline

* **Acknowledgment**: Within 48 hours of receipt.
* **Assessment & Patch**: We aim to investigate and develop an initial patch within 7 business days.
* **Public Disclosure**: Coordinated disclosure will occur only after a fix is published and deployed.

Thank you for practicing responsible disclosure and keeping the community secure!
